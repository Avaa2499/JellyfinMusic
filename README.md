# • 🎵 Jellyfin Music App

  A high-quality, offline-first music player for Android that syncs with your Jellyfin server.

  ✨ Key Features

  • FLAC playback with gapless transitions (to do)
  • Offline downloads with smart caching (to do)
  • Swipe miniplayer down to stop music
  • Enhanced playlists (create, rename, delete) (to do)
  • Smart search across titles/artists/albums (to do)
  • Pull-to-refresh Jellyfin sync

  🔧 Quick Setup

  1. Download latest APK from releases
  2. Enter Jellyfin server URL, username, password
  3. Sync playlists & download music for offline (to do)
  4. Swipe down on miniplayer to stop playback

  📱 Controls

  • Play/Pause: Tap miniplayer controls
  
  • Next/Previous: Skip buttons
  
  • Stop: Swipe down on miniplayer
  
  • Playlists: Long-press for options menu
  

  🎛 Settings

  • ReplayGain normalization
  
  • Offline mode toggle
  
  • Battery saver mode
  
  • Debug logging
  
  • In app updater


  Requirements: Android 8.0+, Jellyfin server already setup, ~20MB storage  


*** This project utilises generative AI for coding. Where possible, all generative AI is ran locally. All other assets (music, sound effects, icons, ect) have no involvement with any generative AI.***
